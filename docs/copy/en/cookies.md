## Theme preference

The site’s own code stores only your choice of light or dark theme in localStorage under the virand-theme key. This preference keeps the selected theme for later visits.

The site’s own code does not write cookies or use sessionStorage. You can remove the preference through your browser’s storage settings; doing so returns the site to its default theme.

## Umami Cloud

The site’s analytics service is Umami Cloud, operated by Umami Software, Inc. When enabled, the site measures visits, button clicks, questionnaire starts and completions, form submissions and calendar views as events. Only fixed categories are sent, without questionnaire answers, names, contact details or message content.

The site is not configured to install analytics cookies. According to <a href="https://umami.is/docs/faq">Umami’s documentation</a>, its tracker does not require cookies.

According to <a href="https://umami.is/privacy">Umami’s policy</a>, the provider briefly processes technical connection data, such as IP addresses, to deliver requests, calculate visitor identifiers and estimate approximate location. IP addresses are not stored as fields in standard analytics records. The same policy distinguishes those records from operational and security logs, which may include IP addresses.

The site respects the browser’s Do Not Track signal by disabling Umami tracking when the browser communicates that preference. This does not mean preventing all HTTP requests or providers’ technical logs.

## Google Calendar after the form

After form submission, the booking option may display an embedded Google Calendar when enabled. That calendar is an external service.

When it loads, Google may use its own cookies and process connection data under its policies. The site does not control those cookies. See <a href="https://policies.google.com/technologies/cookies">how Google uses cookies</a> and its <a href="https://policies.google.com/privacy">privacy policies</a>.
